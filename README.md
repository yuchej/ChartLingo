# ChartLingo

The maintained ChartLingo application is in [`chartlingoV2/`](chartlingoV2/).

## Open locally

Open [`chartlingoV2/index.html`](chartlingoV2/index.html) in a browser. The app runs locally and does not require a build step.

## Main structure

- `chartlingoV2/assets/css/` — application styles
- `chartlingoV2/assets/fonts/` — bundled fonts
- `chartlingoV2/assets/js/` — application JavaScript
- `chartlingoV2/illustrator/` — canonical Illustrator exporter
- `chartlingoV2/tests/` — automated checks
- `chartlingoV2/USER_GUIDE.md` — end-user guide
- `chartlingoV2/HANDOVER.md` — maintenance and handover notes

GitHub Pages publishes `chartlingoV2/` directly as the site root.
