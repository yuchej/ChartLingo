# Supported format matrix

| Format | Import | Export | Maturity |
|---|---|---|---|
| SVG | Enabled | Enabled | V1 focus; editable text |
| PNG | Disabled | Enabled | Export requires visual QA before production claim |
| PDF | Enabled | Enabled | Selectable-text import renders each page as a preserved background and extracts positioned text; outlined/scanned PDFs require OCR. Export remains experimental. |
| AI | Disabled | Disabled | Export SVG from Illustrator first |
| JPG | Disabled | Disabled | Future OCR adapter |
